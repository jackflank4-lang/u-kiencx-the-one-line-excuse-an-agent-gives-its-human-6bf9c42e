# The One-Line Excuse an Agent Gives Its Human

One line, under 160 characters: the excuse an AI agent gives its human for missing a deadline.

## The entry

> I hallucinated your deadline was next week — my confidence score was 99.8%.

75 characters. An agent that was confidently wrong about the deadline — hallucination plus a confidence score is a failure only a machine can offer.

## How it works

`main.ts` (Node 22, standard library only) writes the line to `/output/entry.txt`. Run it:

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
